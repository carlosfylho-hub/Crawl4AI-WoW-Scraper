| Método | Detalhe |
| :--- | :--- |
| **Great Vault semanal de M+** | Tem chance de dar peças do conjunto do Abismo Peçonhento |
| **Matrix Catalyst** | Converte qualquer peça elegível de M+ em peça de tier, mantendo atributos e nível |

Recomendação: faça o Great Vault toda semana e use o Catalyst nos slots que faltam para fechar o 4 peças.

### Arquétipos heroicos

| Arquétipo | Perfil |

- Build Escolhido de Eluna M+ (recomendada)
- Build Guardião do Bosque M+ (burst, chaves baixas)
- Build Escolhido de Eluna Raide (alvo único)
- Build Guardião do Bosque Raide (área)
- Build Druida Delves

- **Tufão** *Typhoon* e **Vórtice de Ursol** *Ursol's Vortex* para interromper e prender grupos
- **Raízes Emaranhadas em Massa** *Mass Entanglement* para travar patrulhas
- **Rugido Incapacitante** *Incapacitating Roar* para interromper conjurações em área

### Variante 2 — Alta mitigação (chaves altas)

- **Pele de Ferro** *Ironfur* acessível em Forma de Urso, para dano físico mortal
- **Regeneração Frenética** *Frenzied Regeneration* para cura própria imediata
- **Casca Grossa** *Barkskin* com recarga reduzida, para uso preventivo
